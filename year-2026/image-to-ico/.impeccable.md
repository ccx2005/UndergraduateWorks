## Design Context

### Users
Windows 桌面用户，用 JPG/PNG 生成多分辨率 ICO 并应用到快捷方式图标。使用场景：为自制应用、网站、游戏、文件夹自制快捷方式图标。任务单一明确，追求「快、稳、所见即所得」，不希望被模态弹窗打断。

### Brand Personality
精准、沉稳、专业。三词：**precise / composed / engineered**。情绪目标：让用户感到这是可信赖的专业工具，而不是玩具。

### Aesthetic Direction
**深色工作室风**：炭黑（非纯黑）基底 + 暖琥珀单一强调色，气质对标专业影像/开发工具（Lightroom、Figma、VS Code 深色）。
- 反例（明确不要）：AI 感青紫渐变、霓虹发光、纯黑+发光、大圆角糖果风。
- 主题：深色 only（用户已确认，不做浅色）。

### Design Principles
1. **信息密度优先**：一行放得下的信息不拆两行；路径、尺寸、嵌入档位直接展示。
2. **单一强调色**：琥珀色只用于主操作与关键状态，其余层次全用中性灰阶表达。
3. **真实反馈**：预览区用棋盘格底展示透明通道（图标工具的领域细节）；悬停/按下/拖拽有明确状态。
4. **克制装饰**：圆角小（4–8px）、阴影淡、不滥用毛玻璃；装饰服务于信息。
5. **字体分层**：展示/数字用 Bahnschrift（几何感强），中文正文用 Microsoft YaHei UI / Segoe UI；路径与状态用等宽（Cascadia Code / Consolas）。
6. **不打断**：转换结果以内联状态面板反馈，不用模态弹窗打断流程。
