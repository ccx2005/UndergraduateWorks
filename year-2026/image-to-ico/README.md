# 图标工坊 · 图片转 ICO

一个用 PyQt5 写的桌面小工具：把 **JPG / PNG** 图片批量转换为 Windows 可直接用于**快捷方式图标**的 **多分辨率 ICO** 文件。深色工作室风格界面，支持自适应缩放、各嵌入尺寸透明预览，并能一键应用到 `.lnk`。

> 适合场景：桌面图标美化、软件/脚本打包前的图标生成、批量整理素材。

---

## ✨ 功能特性

- **批量转换**：多选图片或拖入多张，一键全部生成 ICO，逐条状态反馈、末尾汇总成功/失败。
- **可选嵌入尺寸**：勾选要打包进 ICO 的档位（16 / 24 / 32 / 48 / 64 / 128 / 256），默认全选；多分辨率保证在任务栏、桌面、资源管理器不同缩放下都清晰。
- **各尺寸透明预览**：转换后按选中项渲染 ICO 内每个嵌入尺寸的缩略图（棋盘格底），一眼看清清晰度与透明通道。
- **应用到快捷方式**：勾选后把选中项的图标直接写入 `.lnk` 快捷方式（依赖 `pywin32`）。
- **透明通道保留**：PNG 的透明区保留，JPG 无透明则背景不透明。
- **自适应缩放 UI**：窗口尺寸变化时字号/间距/预览区等比缩放，文字比例放大 1.5×，高分屏也好读。
- **拖拽导入**：预览区或整个窗口均可拖入图片。

## 📦 安装与运行（源码）

### 环境依赖

- Python 3.8+
- PyQt5
- Pillow
- pywin32（仅 Windows，用于 `.lnk` 应用；缺失时优雅降级）

### 安装

```bash
pip install -r requirements.txt
```

### 运行

```bash
python main.py
```

### 打包成 exe（可选）

已用 PyInstaller 打包为单文件可执行程序（`dist/ImageToIco.exe`，双击即开，无需 Python 环境）：

```bash
pip install pyinstaller
pyinstaller --noconsole --onefile --name ImageToIco main.py
```

生成的 `dist/ImageToIco.exe` 即为绿色可执行文件。

## 🚀 使用步骤

1. **添加图片**：点击「添加图片…」多选，或把图片拖入窗口 / 预览区。
2. **选择嵌入尺寸**：在「嵌入尺寸」区勾选需要的档位（默认 7 档全选）。
3. **（可选）应用到快捷方式**：勾选后选择目标 `.lnk`，转换完成后自动写入图标。
4. **开始转换**：点击「开始转换」，输出 ICO 默认与源图同目录、同名。
5. **查看预览**：选中队列中的某一项，下方会展示该 ICO 内每个尺寸的透明缩略图。

> 提示：即使不通过本工具，生成的 `.ico` 也能在 `.lnk` → 右键「属性」→「更改图标」中手动选用。

## ❓ 常见问题

- **Q：某些尺寸没有出现在预览里？**
  A：当源图本身小于某档位（例如 100×100 的图不会嵌入 128/256），Pillow 会自动跳过，预览只显示真实嵌入的尺寸，属正常现象。

- **Q：JPG 转出来的图标背景是黑的？**
  A：JPG 本身不含透明信息，会按不透明处理。如需透明背景，请使用 PNG 源图。

- **Q：勾选了「应用到快捷方式」但没有生效？**
  A：需要本机安装 `pywin32`，且对目标 `.lnk` 有写入权限。未生效时工具会提示，可手动更改图标。

- **Q：非正方形图片会变形吗？**
  A：不会。每个档位按原图宽高比重采样（例如 300×200 会嵌入 128×85 而非 128×128），预览如实显示非正方形。
