# 小橘桌宠 · UI 设计规范 v1.0

> 融合方案 A+C：温暖手账主体 + 机能仪表盘监控
> 反差萌设计语言 — 治愈的猫身 + 硬核的数据表

---

## 1. 设计理念

**一句话**：让桌宠既有手账贴纸的温暖治愈感，又有系统监控工具的极客信息密度。

| 维度 | 选择 | 理由 |
|------|------|------|
| 主体调性 | 温暖手账风 | 长时间驻留桌面不刺眼，符合宠物陪伴定位 |
| 监控面板 | 机能工业风 | 数据可读性高，与治愈主体形成反差萌记忆点 |
| 聊天窗口 | 手账气泡 + 机能输入框 | 消息温柔、输入硬核，延续反差感 |

**反 AI Slop 检查**：不是"AI 默认的圆角卡片+紫蓝渐变"，而是有明确美学观点（温暖×硬核）的统一风格。

## 3. 字体层级

| 层级 | 字体 | 字号 | 字重 | 用途 |
|------|------|------|------|------|
| Title | Microsoft YaHei | 13px | 500 | 窗口标题 |
| Body | Microsoft YaHei | 10px | 400 | 气泡/消息文字 |
| Caption | Microsoft YaHei | 8px | 400 | 提示/发件人 |
| Mono-label | Consolas/Courier | 9px | 400 | 仪表标签 CPU/MEM |
| Mono-value | Consolas/Courier | 9px | 500 | 仪表数值 |
| Mono-meta | Consolas/Courier | 7px | 400 | 仪表元信息 UPTIME |

**规则**：手账层用微软雅黑（柔和），机能层用等宽字体（数据感）。两层字体不混用。

### 4.1 主窗口 (220×400)

```
┌─────────────────────────┐ y=0
│  ╭───────────────────╮  │ ← 气泡区 (y=12-40, 圆角10)
│  │ 主人又加班啦？喵~ │  │
│  ╰───────────────────╯  │
│                         │
│         🐱              │ ← 猫咪区 (y=50-280, 居中)
│       (橘猫)            │
│                         │
│ ┌─────────────────────┐ │ ← 仪表盘 (y=290-390, 圆角4)
│ │ [SYS MONITOR] ●LIVE │ │
│ │ CPU ▓▓▓▓░░░░░  42%  │ │
│ │ MEM ▓▓▓▓▓▓░░░  58%  │ │
│ │ ─────────────────── │ │
│ │ UPTIME 02:14  PROC  │ │
│ │ MOOD happy   [CHAT] │ │
│ └─────────────────────┘ │
│           ●             │ ← 状态指示点
└─────────────────────────┘ y=400
```

- 窗口：`overrideredirect(True)` + `transparentcolor=#010101` 透明置顶
- 圆角：主窗口 16px（用 Canvas 绘制圆角矩形）
- 描边：`#EF9F27` 1px 橘色外框

### 4.2 聊天气泡（主窗口内）

- 宽度：160px，高度：按内容自适应（最小 28px）
- 背景：`#FFFFFF` 白
- 描边：`#EF9F27` 0.5px 橘
- 圆角：10px
- 文字：YaHei 10px `#2D3436`
- 显示时长：8秒（问候）/ 10秒（回复）
- 出现/消失：透明度渐变（tkinter 用 `attributes("-alpha")` 模拟）

### 4.3 机能仪表盘（嵌入主窗口底部）

- 容器：200×100，圆角 4px，深底 `#1E1E1E`
- 标题条：14px 高，`#2C2C2A`，左侧 `[ SYS MONITOR ]` 橘色，右侧 `● LIVE` 绿灯
- CPU/MEM 行：标签 9px 灰 + 进度条 120×6 + 数值 9px 绿
- 进度条颜色随负载变化：<50% 橘 / 50-80% 深橘 / >80% 红
- 元信息行：`UPTIME` / `PROC` / `MOOD` / `[DBL_CLK=CHAT]` 7px 灰
- 刷新频率：2秒
- 字体：所有等宽 Consolas

## 5. 动效规格

### 状态切换动效

| 状态 | 动效 | 周期 |
|------|------|------|
| 待机 idle | 身体上下浮动 ±2px + 尾巴摆动 | 2s 循环 |
| 开心 happy | 左右摇摆 ±5° + 冒爱心 ♥ | 3s 后回 idle |
| 睡觉 sleep | 闭眼 + 呼吸缩放 0.98-1.02 + 冒 Zzz | 持续 |
| 吃饭 eating | 张嘴咀嚼 + 冒爱心 | 4s 后回 idle |

### 气泡动效

- 出现：alpha 0→1，200ms
- 消失：alpha 1→0，300ms
- 思考中："思考中" + 点数循环 `. .. ...`，每 500ms 切换

### 仪表盘动效

- LIVE 灯：opacity 0.5↔1.0 闪烁，1s 循环
- 数值更新：直接刷新（不做过渡，保持极客感）
- 进度条：宽度跳变（不做缓动，保持数据感）

## 6. 状态机视觉映射

| 状态 | 眼睛 | 嘴 | 特效 | 仪表 MOOD 字段 |
|------|------|-----|------|----------------|
| idle | 圆睁 + 偶尔眨眼 | 微笑 | 无 | `idle` |
| happy | 眯眯眼 `︶︶` | 开心张大 | ♥ 飘出 | `happy` |
| sleep | 闭眼 `一一` | 小 o | Zzz 飘出 | `sleep` |
| eating | 圆睁 | 张嘴 ○ | ♥ 飘出 | `eating` |

仪表盘底部 `MOOD` 字段实时反映当前状态，强化"猫与系统一体"的设计语言。

## 7. tkinter 实现注意事项

### 可实现
- 圆角矩形：Canvas `create_arc` + `create_rectangle` 拼接，或用 `create_polygon` + `smooth=True`
- 等宽字体：`Consolas` / `Courier New` Windows 自带
- 透明窗口：`overrideredirect` + `-transparentcolor`（已验证）
- 置顶：`-topmost`（已验证）
- alpha 渐变：`attributes("-alpha", value)` 0.0-1.0

### 不可实现（需规避）
- 真正的毛玻璃模糊（用纯色替代）
- 阴影（用半透明黑色椭圆模拟地面阴影）
- 渐变填充（用多个色块拼接近似）
- 旋转动画的丝滑插值（用 `after` 步进近似）

### 性能要点
- Canvas 重绘频率：动画 50ms / 帧（20fps），仪表 2000ms / 次
- 气泡 alpha 渐变用 `after` 步进，每 20ms 改 0.1
- 避免在 `_draw` 里创建新对象，尽量 `itemconfig` 复用
