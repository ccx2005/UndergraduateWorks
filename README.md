# UndergraduateWorks

本科期间的课程作业、实验与毕业设计归档仓库。

## 目录结构

| 目录 | 说明 |
| --- | --- |
| `year-2022/` | 大二课程作业与实验 |
| `year-2023/` | 大三课程作业与实验 |
| `year-2024/` | 大四课程作业与毕业设计 |
| `graduation-project/` | 毕业设计（论文 + 源码） |

## 使用约定

- 每个子目录下放置 `README.md`，说明课程/项目背景、环境依赖与运行方式。
- 源码按语言/框架合理组织，保持目录清晰。
- 请勿提交大文件、密钥与敏感数据，参考 `.gitignore`。

## 提交规范

建议分支命名：`feature/<课程或项目名>`；提交信息清晰描述改动。
